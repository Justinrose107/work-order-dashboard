统计规则与区域映射

Work Order Status 为 Closed / Close / 已关闭 / 关闭 / Cancelled / Canceled / 已取消 / 取消时排除；流程状态 Completed 不等同于工单关闭。重复工单号按原始行保留并提示，避免自行选择记录。所有数量均按记录行统计。

无时区的时间按上方所选时区解释，默认北京时间；每分钟自动刷新。未填完成时间不能判断是否超期，因此与已超过 72 小时的工单分开展示。刷新网页会清空导入数据。
